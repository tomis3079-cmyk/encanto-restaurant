# Encanto Restaurant & Terrace Website

A beautiful, modern website for Encanto, a fine dining restaurant and terrace located in Starozagorski bani.

## 🏠 About

**Encanto** is a premier restaurant and terrace offering:
- Fine dining experiences
- Beautiful outdoor terrace setting
- Elegant ambiance for special occasions
- Exquisite Mediterranean cuisine

## 📍 Location

**Address:** Starozagorska, 6062 Starozagorski bani

## 🌐 Website Features

- **Responsive Design:** Works perfectly on desktop, tablet, and mobile devices
- **Smooth Navigation:** Easy-to-use menu with smooth scrolling
- **Hero Section:** Eye-catching landing area
- **About Section:** Information about the restaurant
- **Menu Preview:** Showcase of appetizers, main courses, and desserts
- **Contact Form:** Easy reservation booking
- **Interactive Elements:** Animations and hover effects
